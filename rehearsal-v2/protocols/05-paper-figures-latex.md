# 05 论文、图表与 LaTeX/PDF v0.2

## 先设计论文论证，再按证据写作

以用户确认的七部分逻辑组织：①Title / Summary / Keywords；②问题重述与分析；③假设与符号；④模型建立与求解（各问含验证、结果、解释）；⑤灵敏度与不确定性；⑥模型评价（优缺点、改进、结论）；⑦参考文献。必要附录另列但仍计入适用的主报告页数；AI使用报告独立。没有通用的官方“O奖目录”，目录按题问和模型依赖调整，规则按年份读取。

先填写 paper/paper-plan.json：题问覆盖、主张、章节/篇幅预算、图表用途、作者，以及 result_generation、consumed_result_refs、verification_refs。每个结果/验证引用包含 artifact_id、path、version、sha256、generation；三元批准引用不能与旧路径拼接。正文结果、图注、摘要和结论消费同一固定代次。主稿由论文负责人唯一整合；写作、绘图和排版各自提交独占目录，交稿不直接覆盖主稿。

摘要最后写，但骨架和方法可提前写。每问形成“目标—假设—必要方程—求解—验证—结果—意义/边界”闭环。避免前半篇全讲不能做什么，后半篇却没有明确题问答案。内部任务号、Agent对话、哈希、审计计数、未执行方案和写作提示不放入正式论文。机械可编译不等于内容完整。

## 图表技能、契约与证据

Python后端已选定时继续使用，不重复询问。优先实际读取本机科研图表技能（例如 nature-figure 或科研可视化工具）的契约、Python片段及QA说明；找不到时记录缺失，使用本项目明确的本地规范，不谎称已经调用外部技能。期刊技能的字号、图量和版式不能覆盖用户的MCM要求。

先填 templates/figure-contract.json：一条论点、题问、图型理由、输入 path/version/hash/generation、字段与单位、变换与排除规则、比较组、样本/场景数、不确定性含义、最终物理尺寸、脚本/命令/脚本hash、输出、英文图注。skill_read保存实际读到的文档摘要与hash；skill_executed保存真实命令、退出状态和QA输出引用。qa_readback必须真实读回产物hash；未看图时 visual_reviewed=false。

通常只需要1–2张有用的示意图。定量图按结果证据、题问和论证缺口决定，不设凑数门槛。优先补结果对照、误差/残差、参数/结构敏感性、分布/区间等有解释价值的图。无法取得有效结果时保留缺口，不编造数据或填“看起来合理”的曲线。数据、数值处理或公式变更交回原建模/编程负责人，再由非作者验证。

## 最终尺寸与统一科研风格

config/figure-style.json使用白底、蓝/青/绿/橙和必要中性色。颜色以外辅以线型或符号；避免彩虹色、炫光、过密框图与无意义装饰。默认图宽165.1mm（6.5in），正文以同一尺寸插入，图内所有文字在最终尺寸至少12pt。这里12pt是本项目用户要求，不宣称是所有竞赛/期刊共同规则。数学上下标也计入实际最小字形，不能只设置主字号再缩小插入。

图注要说明变量、单位、场景、数据性质、比较对象及误差/区间定义。理论示意、合成演练与实测严格区分。保留绘图脚本、固定输入、PDF、可编辑SVG与300dpi PNG；PDF中文字可提取。排版时避免再次缩放导出画布，不用 tight crop 偷改约定物理尺寸。

scripts/figure_demo.py 的 new_plot_canvas(style, panels=1/2) 提供最终尺寸单图与上下双面板模板。双面板默认等宽等高；实际加完数据、图注和图例后仍须按技能运行 require_matplotlib_panel_alignment()，不能把模板等宽测试冒充最终图对齐通过。若需要并排窄面板，先精简文字或增加独立图，保持最终12pt。

运行 python scripts/figure_check.py --root PROJECT RELATIVE_CONTRACT。该工具核输入/输出/脚本与QA读回hash、PDF尺寸、最终缩放字号及明显文字原点越界；它不证明完整字形/图像无裁切、不自动证明科学有效或美观。多面板必须用实际渲染的绘图区边界做对齐审计；单绘图区记录不适用及原因，不能冒称做过多面板测试。有本地nature-figure时按其说明实际运行源审计、PDF字形和碰撞检查，再逐张读图；失败不伪造通过记录。

## 原生公式与简明文字

公式使用 equation + aligned、align、cases 等原生LaTeX环境；按等号/关系号对齐，长式合理拆行，必要式才编号并通过label/ref引用。变量首次出现给物理含义和单位；图表/公式前说明用途，后说明允许推出的结论。断行、字体等表达修复不自动变成科学改模；符号、公式或判据实质变化须由模型负责人确认并复验。

引用支持数据、参数、方法与关键事实，不以篇数目标删证据。压缩无助解题的综述、重复题面、贴近原文的表述和冗长内部核验注释；保留真实出处，内部访问/核验日志放证据登记。引用数量不直接代表查重率，不为降重隐去借鉴关系。

## 构建、内容、视觉和发布分别验收

python scripts/paper.py --root PROJECT build 使用隔离XeLaTeX副本，拒绝源码在构建中漂移，保存PDF/源码/结果引用/警告/逐页渲染hash。draft可以编译，但 content_status 与机械结果分开；RESULT PENDING、no_run_yet、DRAFT、TODO/TBD等残留阻断release。默认骨架包含提示，因此不是可提交成稿。

release必须同时通过：当前PDF和源码对应、内容无内部占位标记、H2有效且正文结果与验证属于记录代次并在批准scope内、H3确实绑定该PDF、独立视觉回执覆盖每一页。活PDF不属于H2结果批准对象；H3才绑定最终PDF字节。

paper-plan.json 的 figures 逐项写 figure_id 和 contract_ref（path、sha256）。构建记录 figure_refs；发布时读回契约、数据、脚本、导出及QA文件，任何哈希漂移或过小字号/低分辨率PNG均阻断。独立视觉回执还须核入稿缩放和图例遮挡；契约审计通过不代表最终入稿视觉通过。

templates/paper-visual-review.json只能在真正逐页查看后填写。回执绑定PDF、build manifest、逐页图片hash与检查项，涵盖裁切、重叠、文字/公式/图可读、图内最终字号和页眉。缺页、改图、换PDF、失败检查、作者自审均不能作为独立发布复核。程序验证既有回执，不自动生成 passed 或伪造实际独立签署；这不是防恶意伪造的密码学身份认证。

## 隔离演示

在独立项目运行 python scripts/figure_demo.py --root PROJECT；可加 --skill-root INSTALLED_NATURE_FIGURE_DIRECTORY 实际执行已安装技能审计。默认输出figures/figure-demo，目录已存在则拒覆盖，改用新目录或新演练项目。演示真实计算 y'=-k*y 的Euler/RK4/解析对照，导出1方法总览和3定量图、CSV、图注契约、解析检查、宏和QA记录，全部 synthetic=true。参数包络不是置信区间。

默认输出存在时，paper/demo.tex选择新四图示范正文与Summary；否则保留旧allocation示例兼容。生成四图后运行 paper.py build --demo。演示只证明管线和数值内部一致；独立视觉、科学复核与H2/H3保持未签署，正式上传仍需用户另行明确授权。
