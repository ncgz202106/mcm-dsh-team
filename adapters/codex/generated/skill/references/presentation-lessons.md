## 2. 让全文容易读的具体做法

- **摘要按答案组织。** 已看的 A/B/C 首页均按任务或模型分段，方便定位；但 A/C 首页量化结果偏少，不能照搬。每段保留必要方法，补上最终结果、共同比较口径和意义；验证与主要边界也进入摘要。B p.1 的不确定性和敏感性数字说明量化信息可以放入摘要，但百分数仍需说清指标和条件。
- **加粗承担导航。** A p.1 和 C p.1 的加粗覆盖较多，会削弱真正关键结论的辨识度。优先加粗短任务标签、少量最终数字或最关键判断，整段结论无需全部加粗。
- **先说明为什么，再写怎么算。** A p.7 的机制到方程、C p.13–16 的概念到代理再到简化网络，均适合迁移；不要直接从模型名称跳到大公式。每个式子之后说明各项对应什么现实过程、单位和边界。
- **版式用稳定层级。** 样本页采用单栏、衬线正文、黑色层级标题、细线页眉和居中图注。抽取到的正文常见字号约为 12 pt、次级标题约为 14 pt；这些只是历史 PDF 的字体测量，不能据此判定新赛季合规或规定必须用某种字体。优先保持正文、标题、图注/图内文字的角色一致，数学符号完整，避免靠缩字容纳信息。
- **图和正文共同完成解释。** A p.15 先说明实验再给两图，B p.19 图后紧接更新假设和公式，C p.20 先说明成功与失败再给多案例图。每张图在相邻正文写比较条件、关键数字、机制/决策意义和限制；图注负责样本、单位、区间与来源，不能只写泛称标题。
- **表格服务选择。** B p.16 的方案表与文字决策相邻值得学；重绘时补单位、对齐数值和适当小数位，宽表不能通过不断缩字解决。B p.23 的 memo 把设备建议汇成行动表，可学习面向对象改变表达密度；不必照抄其长背景段。
- **按最终页面检查。** 原论文中多处大框架和多面板虽然结构有用，图内字仍明显小于正文。应按计划插入宽度生成，检查完整图、最终 PDF 100% 页面与灰度效果；页数紧张先删低价值信息、拆分职责或重组布局，而非降低可读性。

## 3. 可复用的分析与写作工作顺序

这是外显的工作表，不要求记录内部推理过程。

1. 把题目每个动词变成可交付量：要估计什么、比较什么、决策什么，用哪项指标判断完成。
2. 为每个量写输入、单位、时间/空间尺度、信息截止和可用证据；区分真实观察、代理量、模拟量与未能识别的量。
3. 先得到可检查的简单基线，再只增加解决具体缺口的机制。A 的固定/变化机制比较、C 的基线残差与网络简化是可借鉴的实验思路，不是指定模型答案。
4. 把前问输出作为明确对象传到后问，包括分布/区间、情景和使用条件。B 的任务链可以用来检查“前问算完却未被后问使用”的断点。
5. 提前写出会推翻当前推荐的测试：边界、机制开关、留出样本、替代定义、冲击或数据不足。C 的失败窗口和小样本讨论提示：反例也是结果。
6. 建一张简短论证表：`题问 → 主张 → 结果文件/字段 → 图表 → 验证 → 下问接口`。图型、模型名和页数分配都服从这条链。
7. 结果冻结后再写 Summary、Conclusion 与 memo，统一最终数字；最后处理语言和页面。任何“稳健、显著、准确、最优、普遍适用”都回到对应证据检查。

## 4. 用户偏好立体图时的条件策略

资料包反对“无意义 3D”有合理依据，但其“只有不可省略的物理空间才允许”是作者建议，不作为全局硬禁令。在用户偏好立体表达时，以下结构应主动评估 3D 方案：

| 数据与论证结构 | 可尝试的 3D 表达 | 必须同时保留的读数支持 |
|---|---|---|
| 真实空间中的轨迹、地形、流场或几何边界 | 三维轨迹/场，必要时两个互补视角 | 起终点、方向、三轴单位、边界、俯视或深度剖面；有不确定性时显示其含义清楚的包络或投影 |
| 两个独立连续参数共同决定一个响应 | 响应面、带等高线投影的曲面 | 原始采样点/网格范围、峰谷与可行域；配热力图、等高线或关键切片供精确比较，不用平滑制造未计算的极值 |
| 三个有实际含义的变量展示分组或轨迹结构 | 三维散点/参数轨迹 | 关键对象直标、遮挡检查、二维投影；静态页面能看清主要结论，交互旋转可作为本地探索工具 |

直接案例是 **2024 B，2407038，p.11，Figure 6**：两幅不同视角的三维潜器轨迹使深度与水平位移同时可见，第三维有实际意义。不过原图缺少清楚的起终点、时间编码和不确定范围，不能把“用了两视角”当作已通过验收。

只有类别柱、装饰厚度或没有实际量含义的第三轴时，不添加透视。其他情形也不以立体感替代数据：先检查遮挡、透视失真、色标、共同轴域和最终尺寸可读性；图能否支撑主张决定是否入稿。科学诚实、来源与不确定性要求对 2D/3D 完全一致。
