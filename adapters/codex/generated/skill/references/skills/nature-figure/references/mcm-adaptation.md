# MCM A/B/C 图表与证据表达

仅在任务明确属于 MCM A/B/C 时使用此分支。它补充科研绘图方法，不导入期刊的图数、栏宽或投稿结构要求；其他任务仍走原流程。

美赛作图或美化时，先按[视觉配方](mcm-visual-recipes.md)的选图表读取最相关1–2项：预测与残差、敏感性与决策、Pareto权衡、配对分布、策略小图或空间小图。其原创可运行脚本为`../scripts/mcm-gallery.py`，示例均为合成数据。不要只引用Skill名称、把整个图库装入上下文或机械套图；选择理由、面板职责、实际读取记录留在现有figure-contract/context pack中。方法图仍用专门矢量路线，字体/色号以项目配置为准。

## 先给图分配论证职责

本用户的美赛项目要求每个必要的结论小节有直观且审美统一的图或表。接收小节主张与证据映射后作图，至少说明主要发现、比较对象、数据版本与最终版面；不能仅按全篇图数满足要求。共享图须在对应小节解释并引用。纯定义、参考文献和AI说明等不为配图而造数据，例外交论文负责人和非作者审阅。优先用直接标注、共享尺度、互补面板和留白层次提升阅读效率。

先写读者要判断的问题、主要发现和必要比较，再选择图型。多面板应承担互补职责，例如过程响应与差值、实际预测与失败区间、机制示意与定量检验。删去一个面板若不损失推理信息，应考虑合并或删除；不按指标数量机械拼图。先交粗图与一句发现，由论文负责人确认信息价值后精修。

仅消费任务指定版本的数据与结果。新的指标、过滤、估计、检验或仿真交回建模和编程角色，不在美化时改变科学内容。参数包络、置信区间、预测区间和重复运行分布分别定义；没有不确定性依据时不添加装饰性误差带。

按证据需要选择表达，不固定图数或图型：

- 轨迹或方案重叠时，考虑共享坐标小图与端点标记；相同量、单位和比较目的使用共同尺度。
- 同一对象或随机ID下的比较，先核对配对键与缺失处理，再展示差值；经验分位区间、ECDF或密度图按样本与问题选择。密度图说明平滑方法，不将平滑形状解释为新增机制。批准的描述性重表达保留公式与字段映射，不暗加推断。
- 单因素低/基准/高试验保留全部已算点，基准也可能在两端范围外；折线仅引导阅读，不据三点假定单调、拟合连续响应或声称全局敏感性。
- 离散情景保留实际测试格点；阈值或行动问题可并置收益与决策变化，或用共同参照及百分点差值。没有真实第三维、流量或多目标定义时，不为外观推荐3D、Sankey或雷达图。

缺失、失效与无定义分开表达；ND不能补零或连线跨过，必要时给出有效样本与存活计数。重复结果的分布或分位带不是效应估计的CI，边际概率区间也不是配对差值区间；复杂推断回统计或验证角色核验。

## 按最终页面设计

在用户偏好下主动评估有意义的三维表达：真实空间轨迹/场、两独立连续参数决定响应、三个实际变量的结构散点。三维图配等高线、切片或二维投影，检查视角、遮挡、采样和三轴单位；可运行起点见`mcm-visual-recipes.md`的`mcm-advanced.py`。不把立体图局限为物理几何，也不把装饰透视当高级。

从项目 `config/figure-style.json` 读取字体、色板、尺寸和字号下限，不自行复制另一组色号。同一对象跨图保持同色，辅以线型或标记；白底、清楚层级、浅辅助线，避免图例盖住数据。方法图不强加坐标，定量图按需要标出变量、单位、尺度和样本或情景数。

最终字号服从项目要求；项目明确12pt时，应在实际入稿尺寸满足，不能用原画布字号证明缩小后合格。拥挤时简化、扩大或拆分，不靠缩字塞入。正文引用、caption和图内标题避免重复同一句话。

## 交付与独立检查

保留绘图代码、数据映射、英文图注、矢量PDF、可编辑SVG及所需PNG。保存前按真实轴范围断言全部有限绘图点及误差条/带端点可见，含负值、零点和区间端点；若明确采用截断轴，说明截断与完整范围，不能悄悄裁掉反例或不确定性。轴域检查与字体/碰撞检查分别记录，后者通过不能证明数据完整可见。

项目提供`scripts/visual_range.py`时，可用`require_visible_data(points, ax.get_ylim(), lower=lo, upper=hi)`核最终纵轴，横向区间用`ax.get_xlim()`；它不改值、不推断统计正确性，也不替代实际看图。旧项目无此工具时用等价数值断言，不把工具缺席误当允许裁切。

看完整图与最终PDF页面，再核图注中的对象、样本、单位、条件和区间方法。编程或验证角色核数，论文负责人核表达，排版核入稿，指定非作者验收；机械通过不等于审美或科学通过。已批准的具体任务说明可作为设计简报，不因载入此分支重复索取相同确认。
