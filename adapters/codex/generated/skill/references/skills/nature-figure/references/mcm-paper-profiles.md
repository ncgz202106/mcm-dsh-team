# 美赛论文的图文设计入口

美赛任务以当前题问、用户论文骨架和已有证据为先，设计参照优先用已读的美赛完整论文页面。11张通用科研图用于局部编码/拓扑补充；通用期刊或软件自带皮肤不能覆盖论文任务。本文件提炼用户资料包的写作与可视化方法，不发布其原论文、图像或整理原稿，不直接采纳其中的科学结论。

2026-11-15重新找到早期资料副本，2024 A/B/C三篇PDF与2026-11-13阅读记录哈希一致。本轮实际查看4篇9个物理PDF页：2024 A 2405424 p.13/17，2024 B 2407038 p.4/19，2024 C 2401298 p.16，2025 C 2510006 p.7/14/16/23。2024 B和2025 C的这些页，正文印刷页码比文件页序少1。奖项标注沿用材料，本轮不重新认证奖项或复算其模型；2023 E旧样本未重新取得，不声称本轮重看。

## 每个任务选一个主设计

| 当前论文需要什么 | 直接观察到的结构 | 如何迁移，以及保留哪些表现力 |
|---|---|---|
| 全文研究路线与跨问衔接 | 2024 B p.4 Figure 1：环境、轨迹、装备、搜索分成任务带，并与章节对应 | 画题问分组、共享状态和前后输出；允许轻量色带、容器、局部实物/坐标提示。缩减微型文字，把细节放局部图；不能退化为不交代接口的算法名清单 |
| 机制、符号与方程相接 | 2024 A p.13 Figure 7：资源、比例、种群及正负反馈；图前后有解释 | 保留关系方向、符号、反馈回路和真实适用条件。定义清楚时可用区域/状态容器和领域示意；粗底、细碎小字需重绘，视觉上的闭环不证明稳定性或因果 |
| 基线与变化的对照 | 2024 A p.17 Figure 12：共同实验条件下看响应；其后与变化机制对照 | 冻结共同输入和参照，按实际数据画状态响应与差值/恢复指标。不同单位优先对齐分面；在图旁解释效果与代价，保留失败情景，不把所有模型压成一个分数 |
| 模型构件怎样递进 | 2024 C p.16 Figures 9–10：先解释一个构件，再组合长短时间层，跨层连接突出 | 建模正文按“基线缺口→新增结构→新增接口→验证”推进；保留必要层级、浅底分组和区别连接。复杂结构本身不丑，重复图标、小字和不清楚的时序才需要改 |
| 算法步骤与数学更新对应 | 2024 B p.19 Figure 9：同一网格中区分已搜、当前、下一中心，紧接更新公式 | 用共同坐标、数值/状态色阶、路径和短标注解释一步操作，再给一般公式。区域、热图与方向有信息时保留；“已搜格永久置零”等假设要另外核验 |
| 预测、验证和不确定性同时可读 | 2025 C p.14 Figures 12–13，p.16 Figures 16–17：局部检验与完整训练/测试/预测视图，历史/预测/区间同组比较 | 保留互补面板、共同对象及清楚区间；画测试边界、基准和失败窗口。需要时用区间点图代替拥挤柱图。原文CI/PI口径或“高精度”表述未经核验不能照搬 |
| 灵敏性如何改变结论 | 2025 C p.23 Tables 8–9：同一阈值下两类输出对照，有的对象不变，有的明显改变 | 先定义扰动范围与共同分母，再用响应、差值、排名/决策变化或配表呈现。报告局部稳定和敏感对象，不能因为少数行恒定就说全模型稳健；名义区间水平变化与参数敏感性分开 |

2025 C p.7的分类散点可说明概念/组别如何进入后续任务，但其坐标含义仍需文内解释。不要把符号情景图的排版距离当作这样的计算坐标。区分“哪一图型合适”和“该论文的计算是否正确”。

## 保留表现力，去掉干扰

- **分组有用途才画。** 问题阶段、时间层、变量子系统与对照情景可用容器、浅色带、边界和少量领域符号。不要把所有图都变成无框文字，也不把每个词装进彩色卡片。
- **颜色先有含义。** 同一变量/策略跨图同色；分组可有低饱和色，定量场可有连续或有零中心的发散色阶。主强调色和对照色是起点，不是全篇只能两色的配额。保留图例、单位与灰度冗余编码。
- **复杂性由任务决定。** 实际网络、地图、概率网格、响应曲面、时序与多面板都可成为主图。有真实空间或三变量关系时保留条件3D及二维读数。不能为紧凑删掉有效证据或把必要整页图缩小。
- **图文一起设计。** 图/表靠近首次解释；公式交代过程与定义，图表给比较和结果，正文写发现、数字、意义和边界。图注补样本、口径、区间、单位与来源，避免重复三遍标题。

## 把资源包变成实际简报

论文负责人按必要结论小节选1–2个相关页面，给图表角色的简报使用现有figure-contract/context pack：

1. 当前题问与主要结论；结果路径、版本和哈希，或固定模型接口。
2. 主设计：研究总览、机制、对照、递进、一步更新、预测区间、敏感性/决策。
3. 参考的论文/物理页/图表号；学习其论证动作与分组方式，指出原图不采用的缺点。
4. 继承输入/输出及变量、单位、边界；每个面板和箭头的实际职责。
5. 本页安排：公式、图表、解释的顺序，最终尺寸，是否需要局部放大或整页。
6. 独立核数与视觉复验范围。换数据后重核图、正文、摘要和审阅版本。

不增加固定图数、每节强制一种图、模型层数或人工关口。现有`mcm-schematics.py`等教学图只提供局部语法，不能默认拿“Shared input→Candidate A/B/C”当美赛整篇路线图。若主设计需要真实领域结构，按任务重新绘制，不能只替换几个名词。

## 写作、审阅和终稿

沿用用户七部分功能骨架。摘要按题问给方法、关键结果、比较口径和意义，最后给主要验证与边界；不把算法列表当摘要。模型建立与求解按子问完成证据闭环，敏感性解释推荐是否改变，模型评价用已有结果说明适用性、成本和不足。

独立审阅先核科学主线与图文一致，再核完整图及实际页面。只看配色或只看编译通过都不够；以`paper.py finish`和现有整改流程重验裁切、缩放、图注、引用与空白。保留当年规则校核、真实H0/H1/H2/H3以及当前结果批准，不从资料包推断新批准。
