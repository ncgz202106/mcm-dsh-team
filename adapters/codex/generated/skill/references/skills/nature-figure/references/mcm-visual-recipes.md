# 美赛图表：可复用的视觉设计

本参考把用户提供的写作与图表整理、已读论文的证据组织方法和实际改稿中发现的问题转成原创方法。二手点评不是获奖身份、统计正确性或官方要求的证明；不复制原图、原脚本或示例数值。这里的“高级”指比较容易、层次清楚、证据完整，不指图型稀奇。

每次只读最相关的1–2条。无需运行整套图库再作一幅图。图库使用明确标记的合成数据，是真实可执行的设计示例，不是生产数据入口或真实论文结果。

| 读者要判断什么 | 组合方式 | 图库配方 | 适用边界 |
| --- | --- | --- | --- |
| 预测在哪失效 | 预测/参照/区间，上下对齐误差 | `prediction` | 标出测试起点；预测区间来自已验收方法，不从残差临时捏造 |

| 多策略为何难比较 | 共享轴小图＋共同灰色基线＋端点 | `strategies` | 同条件同指标；直接标签避免反复找图例，不隐去劣势系列 |

| 不同情景如何分叉 | 历史锚点＋情景扇形/区间＋驱动路径 | 按需定制 | 区分情景范围、CI、PI和重复分布；直接标情景，不把扇形带当精确预测 |

| 资源如何分配 | 守恒流图＋总量/单位 | 按需定制 | 每个节点入流=出流+显式损耗/存量变化；无真实流量不用Sankey |
| 多维设计是否有折衷 | 可比指标点图/热图，必要时平行坐标 | 按需定制 | 雷达面积受轴顺序和归一化影响；有真实第三变量时评估3D，并提供二维读数 |

## 将审美变成可执行选择

1. **确定视觉主次。** 蓝色主线、灰色参照、暖色阈值是一种安排。也可选亮色、渐变、彩底或光影来区分角色和营造质感。按美赛参考与本篇样式选色，并在实际阅读时确认主要比较仍醒目。
2. **先定最终尺寸。** 本项目全宽默认165.1mm，核心字至少12pt；这不是所有美赛或期刊的通用字号规定。两列面板各约65–70mm时只放短轴名和少量刻度；长变量名改成上下布局。最终字高=源字号×入稿宽/源图宽，调整或拆图优于缩字。
3. **面板为推理服务。** 主结果配误差/分布/决策一个补充面板；六个小面板适合重复同口径比较，不适合塞六个不同故事。字号保持，面板数不做目标。
4. **对齐绘图区。** 相同量用同尺度；不同量可共用横轴并上下排列。色条和图例有独立空间。主图上下空间随数据调整，但不靠紧裁切改变导出物理宽度。
5. **标注只突出关键。** 标出参照、阈值、拐点/失败窗口、代表方案及必要数值。直接标签和共用图例择优；数据线或误差带穿字时移动标签，不能用白色遮罩抹掉结果。
6. **色标有语义。** 顺序量用单调明度（如cividis），有真实零中心才用发散色标；跨面板共享范围。灰度下再依赖线型、点型、位置和标签，不仅依赖红绿。

## 每种配方的细节

### 进阶诊断与决策图

按题意选取下列诊断版式，使用任务已批准的计算结果。新验证或指标由上游任务提供。下列版式是美赛迁移建议，方法来源不作为获奖样本。

| 图型 | 要看的结论与实际画法 | 数据和读数核对 |
|---|---|---|
| **双因素决策切换图＋代价图** | 同一网格左画推荐方案，右画沿用某一预先指定方案的增量损失。精确标一个已算情景，解释何时切换及晚切换的代价。 | 用实际求解点、目标方向、费用单位和统一约束。未算、无可行方案、指定基线不可行各自标明。离散计算格不画成精确连续边界。 [Brown 等，Figure 4 的决策分区](https://doi.org/10.1029/2011WR011212) |
| **滚动起点 × 步长误差热图** | 行放真实预测起点，列放预测步长，格子给样本外误差。旁边按步长对齐 MAE 和有效样本数，突出特定窗口或远期崩溃。 | 带符号误差用零中心发散色标，绝对误差用顺序色标。无后续观测的格显示未知。每格只能使用该起点实际可知的训练信息。 [Hyndman 与 Athanasopoulos，滚动起点验证](https://otexts.com/fpp3/toolbox.html#time-series-cross-validation) |
| **空间留出分块＋留出误差地图** | 左画真实验证折号或训练/留出区，右画相同地理范围内的留出误差。选一处高误差区域做同色标放大。 | 需要坐标、投影、样本分块和每点留出预测。保留无观测区，说明块大小与目标是区域内插值还是异地迁移。 [Roberts 等，空间结构下的交叉验证](https://doi.org/10.1111/ecog.02881) |
| **阈值分位点阵** | 两个策略用同刻度的等概率点展示结果分布，突出预算线或失败阈值。小概率尾部直接加数值。 | 从已验证的预测分布或说明权重的情景分布取分位点并交代每个点代表的概率。点数是绘图分辨率，图注另写实际样本数或情景数。 [Kay 等，Figure 2](https://idl.cs.washington.edu/files/2016-WhenIsMyBus-CHI.pdf) |
| **二阶 ALE 热图＋数据覆盖** | 两个相关特征的联合效应可画中心化的二阶累积局部效应，再用邻接面板显示每格样本支持。支持太少的格用明确标记。 | 交代拟合对象、特征单位、分箱、效应单位和中心化方法。该图描述拟合模型的交互，因果或机制结论需独立证据。 [Apley 与 Zhu，ALE](https://academic.oup.com/jrsssb/article/82/4/1059/7056085) |
| **配对均值–差值图** | 比较两种同量纲方法能否互换。横轴配对均值，纵轴两法差值，并标零线、平均偏差、一致性限和研究前已定的工程容差。 | 同 ID 配对。常用的平均差 ± 1.96 个差值标准差需要差值分布与稳定性等假设。重复量测或异方差需另行处理。一致性限和估计量的置信区间分别定义。 [Bland 与 Altman，Figures 2–5](https://www-users.york.ac.uk/~mb55/meas/ba.htm) |

### prediction：表现与误差同时可见

上下共享时间轴，上面给预测与观测/参照，下面给有单位的残差和零线。已知测试边界标在两面板；区间写出预测对象、名义水平、方法和适用区间。相关性或高R²不能代替一致性；若做预测–观测散点，加y=x与等比例轴，并按实际留出方式解释。无区间依据就不加带。图库中的已知生成噪声区间仅是合成演示。

### sensitivity：从变化到选择

保留低/基准/高全部点及参数范围依据，基准可能在两端之外。上下或左右面板分别回答数值如何变、选择会否变；给零线或已批准阈值，不擅设阈值。ND、死亡、不可行单独显示原因和有效样本。只算三水平就画三列格点，不能伪造连续翻转边界。

### pareto：比较选择而非宣布唯一最优

先验证可行性，后算被支配关系。背景点中性、已测试非支配点强调，给目标方向与单位。命名少量备选是阅读辅助，未给偏好/权重不能自动选“最佳”。不连线暗示可行的连续混合；如果连线必须说明只是阅读引导。侧面比较同一候选集的收益差或预算余量，不能添加另一个未定义综合分数。

### paired：看全体差值，避免两堆均值掩盖效果

用共同ID配对后展示全部有效差值。样本适合时用半小提琴＋中位数/IQR＋全体点或ECDF；抖动仅移动类别方向，固定种子且不改变测量值。记录KDE带宽；离群值保留，少样本不让平滑外形制造可信度。不同颜色只代表真实群体或条件。分布上有零点参照；计算效应CI是另一个统计任务。

### strategies与spatial：共同参照让眼睛不用换算

策略小图共享坐标与中性基线，端点可直接标示，共同图例最多一次。空间小图共享色标，掩膜区域保留原因，不把缺失填零；跨期总量或均值的统计口径一致。先画实际测试网格，平滑/插值若是分析结果须另留计算与验证。空间标度或地理信息不足时，不伪装成真实地图。

## 可运行样例与复用

在本Skill目录运行（沿用已选Python后端；不自动安装依赖）：

```text
python scripts/mcm-gallery.py --recipe paired --output NEW_DIRECTORY --style PROJECT/config/figure-style.json
python scripts/mcm-gallery.py --recipe all --output ANOTHER_NEW_DIRECTORY
python scripts/mcm-advanced.py --recipe surface --output NEW_SURFACE --style PROJECT/config/figure-style.json
python scripts/mcm-advanced.py --recipe trajectory --output NEW_TRAJECTORY --style PROJECT/config/figure-style.json
```

缺少项目配置时使用`assets/mcm-figure-style.json`，其源是预设的`bundle/src/figure-style.json`，构建器同步，不能另维护一份近似色。用`--qa-scripts PATH_TO_NATURE_FIGURE/scripts`可运行现有对齐和碰撞检查；已安装Skill时会自动发现相邻脚本。检测缺席明确记为未执行。

用户偏好立体表达时，真实空间轨迹、两独立参数的响应面、三个有意义变量的结构散点主动提出3D候选；能否看清主结论决定取舍。`mcm-advanced.py`另支持`--data FROZEN.csv`：曲面列为`x_m,y_m,response_kPa`，轨迹列为`time_s,x_m,y_m,z_m`，真实任务应按实际变量改写命名与图注。分类柱仍应按同一尺度准确比较长度。任何装饰厚度都需检查其是否影响读数。二维投影、遮挡检查和轴域检查不因使用3D省略。

输出PDF、SVG、300dpiPNG、合成数组JSON、英文图注、面板映射、导出尺寸与检查记录。脚本拒绝覆盖已有目录。复用时只选一个配方，把绘图函数复制到任务独占目录，**从冻结结果加载真实数据并改写数据契约和图注**；不能仅去掉Synthetic字样就把示例当结果。若真实数据尚未具备所需区间/指标，先交建模、编程和验证角色，不让绘图角色补算结论。

## 三维图的科学审美

从优质美赛论文借鉴页面关系。2025 A 2501567 p.14 Figures 7–8 将二维足落密度和带等高投影的磨损曲面邻排，p.19 Figure 11 用四个年限的快照衔接维护讨论。密度和深度各有单位。2024 B 2425792 p.11 Figure 7 用多个时刻的空间轨迹和底部视角解除遮挡，p.17 Figures 12–13 把领域几何与时间分布图相接。迁移时将三维图的形状、运动或空间关系接到问题的实际判断。 [2024 COMAP 获奖名单](https://www.contest.comap.org/undergraduate/contests/mcm/contests/2024/results/index.html) · [2025 COMAP 获奖名单](https://www.contest.comap.org/undergraduate/contests/mcm/contests/2025/results/index.html)

| 当前图要回答什么 | 可选画法与核对 |
|---|---|
| **峰谷在哪里，响应如何变化** | 用低对比背景、可辨网格和清楚的轮廓组织曲面。色彩若编码绝对量，采用明度有序的顺序色标。若编码带符号的偏差，发散色标以有意义的参照为中心。三维面支持观察形状，邻近二维等高图标重点格点、等值或剖面位置。 |
| **空间几何长什么样** | 可用单色柔光、轮廓分层或浅色底面突出形态。图注明确此处明暗表示光照。若使用阴影和数值叠色，提供未加阴影的定量视图。缺测和未计算区域保留，绘制面片或等高线时标出插值依据。 |
| **轨迹何时经过哪一层** | 保留实际坐标、起终点和方向。连续色彩可编码时间或同一个实际量。选一个主相机，再配 XY/XZ 投影、剖面或局部放大解开重叠。比较时间快照时，保持相机、纵横比、轴范围和颜色标度。 |
| **几种情景能否直接比较** | 优先试正交相机与一致的轴比例，保持跨图光照和色标一致。透视图也可用于解释空间。如放大高程或改相机来说明细节，在图注给出说明，并保留可直接比较的视图。 |

审阅时先问高度、颜色和阴影分别表达什么，再复核具体格点与二维图。若明暗改变了数值颜色的感知，调低光照影响或单独呈现无阴影读数图。复杂度和饱和度可随主题与版面变化。 [Crameri 等，科学色标](https://doi.org/10.1038/s41467-020-19160-7) · [Kovesi，色标及地形阴影](https://arxiv.org/abs/1509.03700) · [Matplotlib 投影](https://matplotlib.org/stable/gallery/mplot3d/projections.html) · [Matplotlib 柔光示例](https://matplotlib.org/stable/gallery/mplot3d/custom_shaded_3d_surface.html)

## 看图与入稿才是最后一步

检查分两次：完整图看信息层次、比较速度、留白、灰度辨识、标注；实际PDF页面看缩放字号、图注、邻近引用、拥挤和裁切。程序检查能否定一些坏图，不能给审美自动打通过。读者应能从图指出主结论和限制；若必须先读一段解释才能定位比较对象，重新设计。

图注给口径和区间，正文给比较→数字→解释→边界。独立审阅者按当前版本给具体位置与建议；作者自检不写成独立验收。先核数据，再精修；字体碰撞通过也需检查全部数据和区间是否落在轴域内。
