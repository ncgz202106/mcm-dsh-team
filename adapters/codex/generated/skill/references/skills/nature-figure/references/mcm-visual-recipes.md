# 美赛图表：可复用的视觉设计

本参考把用户提供的写作与图表整理、已读论文的证据组织方法和实际改稿中发现的问题转成原创方法。二手点评不是获奖身份、统计正确性或官方要求的证明；不复制原图、原脚本或示例数值。这里的“高级”指比较容易、层次清楚、证据完整，不指图型稀奇。

每次只读最相关的1–2条。无需运行整套图库再作一幅图。图库使用明确标记的合成数据，是真实可执行的设计示例，不是生产数据入口或真实论文结果。

## 选图入口

| 读者要判断什么 | 组合方式 | 图库配方 | 适用边界 |
| --- | --- | --- | --- |
| 预测在哪失效 | 预测/参照/区间，上下对齐误差 | `prediction` | 标出测试起点；预测区间来自已验收方法，不从残差临时捏造 |
| 参数会否改变建议 | 低/基准/高响应＋离散决策格点 | `sensitivity` | 显示所有已算水平，不把OAT当全局分析；不插值未知阈值 |
| 预算不同如何选 | 可行点、被支配点、前沿＋备选代价 | `pareto` | 写明目标方向/单位/可行域；前沿仅针对已测试集合，不宣称全局最优 |
| 同一对象是否获益 | 同ID差值的分布＋ECDF | `paired` | 先核配对键和缺失；密度/分位数不是CI，少量样本优先直接点 |
| 多策略为何难比较 | 共享轴小图＋共同灰色基线＋端点 | `strategies` | 同条件同指标；直接标签避免反复找图例，不隐去劣势系列 |
| 空间分布如何变化 | 同色标空间小图＋汇总趋势 | `spatial` | 色标固定于所有比较数据；示例只是非地理网格，真实地图另核来源/投影 |
| 模型各问如何相接 | 分层机制链＋命名接口箭头 | 沿用方法图专项Skill | 箭头应有真实传递变量/约束，机制示意不充当实验验证 |
| 网络关系如何变化 | 固定节点位置的符号子图＋完整邻接矩阵 | 按需定制 | 阈值公开，原网络保留；正负、方向与强度分别编码，不堆毛线球 |
| 资源如何分配 | 守恒流图＋总量/单位 | 按需定制 | 每个节点入流=出流+显式损耗/存量变化；无真实流量不用Sankey |
| 多维设计是否有折衷 | 可比指标点图/热图，必要时平行坐标 | 按需定制 | 雷达面积会受轴顺序和归一化影响；真实三维几何才考虑3D |

## 将审美变成可执行选择

1. **确定视觉主次。** 一个主要比较用蓝色强调，基线用中性灰；风险/决策变化才用橙色，另一真实机制可用青绿。实际色值从项目配置读取，不在每图重写配色。不能把每种颜色都画得同样抢眼。
2. **先定最终尺寸。** 本项目全宽默认165.1mm，核心字至少12pt；这不是所有美赛或期刊的通用字号规定。两列面板各约65–70mm时只放短轴名和少量刻度；长变量名改成上下布局。最终字高=源字号×入稿宽/源图宽，调整或拆图优于缩字。
3. **面板为推理服务。** 主结果配误差/分布/决策一个补充面板；六个小面板适合重复同口径比较，不适合塞六个不同故事。字号保持，面板数不做目标。
4. **对齐绘图区。** 相同量用同尺度；不同量可共用横轴并上下排列。色条和图例有独立空间。主图上下空间随数据调整，但不靠紧裁切改变导出物理宽度。
5. **标注只突出关键。** 标出参照、阈值、拐点/失败窗口、代表方案及必要数值。直接标签和共用图例择优；数据线或误差带穿字时移动标签，不能用白色遮罩抹掉结果。
6. **色标有语义。** 顺序量用单调明度（如cividis），有真实零中心才用发散色标；跨面板共享范围。灰度下再依赖线型、点型、位置和标签，不仅依赖红绿。

## 每种配方的细节

### prediction：表现与误差同时可见

上下共享时间轴，上面给预测与观测/参照，下面给有单位的残差和零线。已知测试边界标在两面板；区间写出预测对象、名义水平、方法和适用区间。相关性或高R²不能代替一致性；若做预测–观测散点，加y=x与等比例轴，并按实际留出方式解释。无区间依据就不加带。图库中的已知生成噪声区间仅是合成演示。

### sensitivity：从变化到选择

保留低/基准/高全部点及参数范围依据，基准可能在两端之外。上下或左右面板分别回答数值如何变、选择会否变；给零线或已批准阈值，不擅设阈值。ND、死亡、不可行单独显示原因和有效样本。只算三水平就画三列格点，不能伪造连续翻转边界。

### pareto：比较选择而非宣布唯一最优

先验证可行性，后算被支配关系。背景点中性、已测试非支配点强调，给目标方向与单位。命名少量备选是阅读辅助，未给偏好/权重不能自动选“最佳”。不连线暗示可行的连续混合；如果连线必须说明只是阅读引导。侧面比较同一候选集的收益差或预算余量，不能添加另一个未定义综合分数。

### paired：看全体差值，避免两堆均值掩盖效果

用共同ID配对后展示全部有效差值。样本适合时用半小提琴＋中位数/IQR＋全体点或ECDF；抖动仅移动类别方向，固定种子且不改变测量值。记录KDE带宽；离群值保留，少样本不让平滑外形制造可信度。不同颜色只代表真实群体或条件。分布上有零点参照；计算效应CI是另一个统计任务。

### strategies与spatial：共同参照让眼睛不用换算

策略小图共享坐标与中性基线，端点可直接标示，共同图例最多一次。空间小图共享色标，掩膜区域保留原因，不把缺失填零；跨期总量或均值的统计口径一致。先画实际测试网格，平滑/插值若是分析结果须另留计算与验证。空间标度或地理信息不足时，不伪装成真实地图。

## 可运行样例与复用

在本Skill目录运行（沿用已选Python后端；不自动安装依赖）：

```text
python scripts/mcm-gallery.py --recipe paired --output NEW_DIRECTORY --style PROJECT/config/figure-style.json
python scripts/mcm-gallery.py --recipe all --output ANOTHER_NEW_DIRECTORY
```

缺少项目配置时使用`assets/mcm-figure-style.json`，其源是预设的`bundle/src/figure-style.json`，构建器同步，不能另维护一份近似色。用`--qa-scripts PATH_TO_NATURE_FIGURE/scripts`可运行现有对齐和碰撞检查；已安装Skill时会自动发现相邻脚本。检测缺席明确记为未执行。

输出PDF、SVG、300dpiPNG、合成数组JSON、英文图注、面板映射、导出尺寸与检查记录。脚本拒绝覆盖已有目录。复用时只选一个配方，把绘图函数复制到任务独占目录，**从冻结结果加载真实数据并改写数据契约和图注**；不能仅去掉Synthetic字样就把示例当结果。若真实数据尚未具备所需区间/指标，先交建模、编程和验证角色，不让绘图角色补算结论。

## 看图与入稿才是最后一步

检查分两次：完整图看信息层次、比较速度、留白、灰度辨识、标注；实际PDF页面看缩放字号、图注、邻近引用、拥挤和裁切。程序检查能否定一些坏图，不能给审美自动打通过。读者应能从图指出主结论和限制；若必须先读一段解释才能定位比较对象，重新设计。

图注给口径和区间，正文给比较→数字→解释→边界。独立审阅者按当前版本给具体位置与建议；作者自检不写成独立验收。先核数据，再精修；字体碰撞通过也需检查全部数据和区间是否落在轴域内。
