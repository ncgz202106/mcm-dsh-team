# Synthetic figure families and page examples

These original examples demonstrate argument design and layout, not contest results. They use no held-out competition answer or copied published figure. Every generated data row is retained.

| Family | Evidence role | Data |
|---|---|---|
| 01 method interface | State, time grid, units and bounded parameter transfer | `data/interfaces.json` |
| 02 baseline difference | Shared-load comparison plus paired absolute gain | `data/comparison.csv` |
| 03 reference failure | Trajectories plus signed error in a known regime shift | `data/forecast.csv` |
| 04 sensitivity decision | Cost response plus a discrete action switch | `data/sensitivity.csv` |
| 05 uncertainty semantics | Deterministic parameter envelope versus an assumed-law predictive interval | `data/envelope.csv`, `data/density.csv` |
| 06 cost effect | Discrete frontier plus explicit budget feasibility | `data/decisions.csv` |

`figures/` contains editable SVG, vector PDF, and 300dpi PNG for each family. English captions, data mapping, panel roles and fixed input/output hashes are in `contracts/`. The generator is maintained only at `tools/figure-gallery.py`; `source/figure-gallery.py` is a byte-identical frozen provenance copy, not another maintenance source.

`config/figure-style.json` is generated byte-for-byte from the repository's single default source, `bundle/src/figure-style.json`. Edit the source and regenerate; do not independently edit the snapshot. All quantitative figures use a final width of 165.1mm and a 12pt glyph floor. LaTeX inserts them at that physical width, without shrinking. Body and equations use 12 TeX pt with newtxtext/newtxmath; 12 TeX pt is about 11.955 PDF pt.

## Reproduce

Run at the repository root with the established Python backend:

```powershell
python tools/figure-gallery.py --output gallery `
  --skill-root "$env:USERPROFILE\.codex\skills\nature-figure" `
  --diagram-skill-root "$env:USERPROFILE\.codex\skills\fireworks-tech-graph" `
  --compile-pages --force
python -m unittest discover -s tests -p test_gallery.py -v
```

Omit `--force` when creating a new output directory. Regeneration changes fixed artifact hashes; any previous independent visual review must then be repeated for the new bytes. Skill roots must contain the actual required files and scripts. No external API or image-generation service is used.

Rendering dependencies are listed in `requirements.txt`; the system must also provide XeLaTeX and the packages used by `latex/page-examples.tex`. The page example has no external bibliography. It is compiled twice using XeLaTeX with shell escape disabled; this environment's latexmk wrapper cannot find Perl, so no successful latexmk run is claimed.

## Checks and their limits

- The generator actually reads and hashes the configured Nature Figure guidance, calls its source, panel-alignment, PDF-text and collision tools, and records outputs. These checks do not assess all scientific or aesthetic claims.
- The method SVG is original Python-authored source, checked using all five Fireworks SVG gates. SVG-to-PDF uses svglib/ReportLab; SVG-to-PNG uses CairoSVG. The PDF renderer's default font floor and stream encoding are explicit so the independent text audit can inspect it; rendered glyph measurements are also checked.
- `pages/page-examples.pdf` has six pages covering four types: model, result, sensitivity and decision. Six page PNGs support actual whole-page review. This teaching document is not a complete competition paper.
- Mechanical, content and visual records are separate. Generator contracts and manifest remain `visual_status: pending` until an independent reviewer examines the exact figures and final page renders. No human approval is generated.
- The predictive interval in family 05 is conditional on an assumed known Normal law. It is neither observed calibration evidence nor a confidence interval for the mean. The parameter envelope is deterministic and has no assigned coverage probability.

Read `manifest.json` and `pages/build-report.json` for the current execution results; do not treat the existence of these instructions as evidence that generation or compilation ran.
