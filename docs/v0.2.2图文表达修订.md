# v0.2.2 候选的图文表达修订

首轮六组局部与B/C两组专题对照出现了改善和退步，不能据此声称候选全面胜出。部分成果缺少完整的模式读取证明，其中一例明确未打开模式卡；单对成果的偏好也不能证明某张卡导致了结果。本次保留11张模式卡，针对实际暴露的表达缺口做四项小改。

| 改动 | 实际要求 |
|---|---|
| 缺失语义保持未知 | 不从相邻图借用单位、时间窗或物理前提；当前主张确实需要时交回建模／编程补证，否则分别表达 |
| 数字解释接回计算 | 派生倍率、方向、分母及比较对象继承上游已核验的最小算式见证；写作和润色不自行补算并签署通过 |
| 拥挤时选择粗布局 | 只在拥挤或比较路线不清时，比较同数据、同尺寸和同字号的两个粗布局，再精修一版；简单图不强制多版 |
| 坐标、图注与页面协同 | 不等距数值按实际或明确变换定位，分类连线不冒充连续响应；标签、图注、正文各有职责，并在入稿页检查接续与可读性 |

主要说明分别位于统计、写作和图表适配分支；润色、审阅及相关模式卡只增加短接力，避免重复加载长检查表。用户指定的论文结构、最终字体要求、真实结果绑定、独立审阅和逐页PDF检查继续适用。未增加角色、固定图数、O奖硬指标或新的总控Skill。

四张修改卡首次在目录条目显式登记 `version=2` 和真实SHA：`semantic-transfer`、`baseline-and-error`、`scale-and-semantic-color`、`evidence-proximity`。其余七条沿用原格式；历史任务的固定版本不会被追改。检查器允许旧条目不带这两个可选字段；声明新字段时则要求完整、类型正确并匹配实际文件，拒绝布尔版本或未声明的字节漂移。

本次软件检查、当前源码哈希和非作者审阅分别保存在 [源码检查](../audit/v0.2.2/m3-adaptation-source-verification.json)、[独立审阅](../audit/v0.2.2/m3-adaptation-independent.json)和[证据索引](../audit/v0.2.2/m3-adaptation-evidence-index.json)。这些检查不证明新提示词已改善真实图文输出。

历史对照、案例、图库和既有审阅报告保留原字节与原有结论。后续应先补完约定的统一整改，再用未见过的同类合成任务检验效果；用于反馈的旧用例不能重新冒充独立最终验证。仍须实际查看独立图和插入后的整页，不能用编译、字体或碰撞检查代替审美判断。

本次仅维护候选源码。已安装的预设与Skill没有更新；真实DSH角色、Skill读取及图文效果须在后续安全部署和可见会话中核验。完整A题、H1/H2/H3人工关口及最终发布条件另行完成。
