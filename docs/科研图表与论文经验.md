# 科研图表与论文经验

本页记录可迁移的图文设计与核验方法，供预设维护和任务设计时按需参考；不是固定图型目录、获奖评分标准或新验收关口。不包含用户材料、示例数据或私有项目结果。维护版本仍以仓库现行版本为准，本页不代表任何后续候选已安装、发布或完成验收。

## 先确定图要帮助读者判断什么

为每图写一句问题与主要发现，确定比较对象、共同条件、指标及参照，再选择图型。多面板应补足推理，例如过程与差值、收益与决策阈值、总览与关键切片。已有图能清楚回答问题就保留，不为了“高级”更换图型或增加图数。先用粗图核信息价值，再按最终页面精修。

| 证据结构 | 可考虑的表达 | 需要保留的边界 |
| --- | --- | --- |
| 重叠轨迹或多个方案 | 共享坐标小图、直接端点标记 | 相同指标保持共同尺度；重复间分位带不是均值CI |
| 同对象或共同随机ID的比较 | 配对差值的经验分位区间、ECDF或密度图 | 先核ID与缺失；全体有效配对参与统计，展示抽样须披露；密度平滑不是新机制 |
| 少量单因素水平 | 低/基准/高全部点、必要区间与共同零线 | 基准可能在两端之外；不据三点宣称单调、连续或全局响应 |
| 离散情景组合 | 已测试格点矩阵、小图或带区间点图 | 保留全部相关测试条件，不插值出未经验证的边界 |
| 收益与行动选择 | 收益面板与阈值面板、共同参照点图 | 明确规则和测试范围；百分点收益不等于相对增幅或经济最优 |
| 机制与跨问接口 | 简短机制链与带对象名的箭头 | 对应实际状态、单位和传递方向，不借示意图声称已验证 |

真实第三维、流量或多目标定义缺席时，3D、Sankey、雷达等图型通常不增加证据。图型选择的运行时细节集中在[nature-figure专项分支](../skill-overlays/nature-figure/references/mcm-adaptation.md)，不向每个角色重复搬运完整图库。

## 区分分布、推断与失效

经验分位带、IQR与密度描述重复结果的分布；CI描述指定估计量的不确定性；预测区间、参数包络与数值误差又各有覆盖对象。图注写清方法、样本/情景数与条件，不能统称“不确定性”。同ID配对先核键与顺序，边际概率区间不能平移成配对收益区间；复杂重采样或检验交统计与验证角色。

ND、缺失与零值含义不同。无定义组保留原因与有效样本或存活计数，不补零、不跨越连线，也不以存活者条件均值掩盖失败。有限重复中的零成功或全成功不等于总体确定性。新增描述统计须在授权范围内保留公式和字段映射，新增推断不得夹带在美化任务里。

## 验证数据确实出现在图中

保存前按真实轴域检查全部有限绘图点及误差条/带的上下端点，尤其是负值、零点与基准。轴范围不应只从点估计、最大值或成功组生成。主动截断时交代完整范围与理由；否则裁掉的点或区间就是证据缺失。

数值可见性、字体/几何/碰撞、完整图实看、最终PDF页面实看是不同检查。字体与碰撞全部通过，仍可能存在轴内数据被裁切。程序检查给出数据与轴域的证据，非作者再核图文含义；任何技术检查均不代签用户关口。

新项目自带`scripts/visual_range.py`。在最终轴域固定后调用`require_visible_data(points, ax.get_ylim(), lower=lo, upper=hi)`；横向区间改用`ax.get_xlim()`。工具检查每个实际点与区间，返回显式无定义计数，不自动裁值、补零或调整坐标。图中允许无定义状态时须明确`allow_undefined=True`并在图中说明原因；全组无定义应画带原因的状态说明，而不是一条零线。

## 图注、正文与页面分工

图内标题简短，图注负责对象、时间、单位、样本、区间和条件；正文按“比较→数字→解释→边界”提炼答案，不照读整段图注。机制解释注明是模型支持还是待检验推测。结论应保留条件性，不把少量离散情景或人为阈值写成现实普遍规律。

按最终入稿尺寸设计，共同比较的面板尽量同页、绘图区对齐，同对象跨图保持颜色和线型语义。拥挤先精简标签、重排或拆图，不靠缩字或裁切压页。参考文献后接独立AI使用报告，再接必要附录；正文篇幅不含附录，官方总页数如何计算仍须核对适用年份规则。

## 版本与维护

引用资料时区分已实际查看的原论文、二手点评和模拟演示；模拟例子的数值与检验指标不能迁入真实结果。公开仓库只沉淀自行总结的方法，不复制用户原PDF、图片、源码、身份或私有结果。

主稿仍由论文负责人唯一整合，图表和章节在任务独占路径交付。结果变化重核数字、图文、摘要与建议；仅重绘也更新图源、映射和受影响页面的视觉记录。保留冻结输入与可重生成代码，按新版本留证，不改写历史验收；构建、独立核验、安装、发布和真实用户批准分别记录。
