# v0.2.2：优秀论文经验与整篇论文验证

本版当前为候选，基线为已发布0.2.1提交 `7fc15098ad22811c29478dd95935deedb5889109`。原暂停演练不恢复、不迁移；候选测试与新历史题演练使用独立目录。源码、合成小样或确定性模型夹具通过，不等于真实模型、科学结果或最终稿已批准。

## 本版增量

- 9份MCM A/B/C案例卡（每类3篇），11条按论证目的读取的模式，六类任务均有来源。只保存自编说明、公开来源和物理页码，原PDF和截图不在仓库。
- 五个专项Skill的MCM适配按需读取相关模式，默认1—2条；保留用户论文顺序，不把图数、字体品牌或单篇论文习惯作为普遍规则。
- 六类可运行合成图及四类页面，统一项目样式，交付PDF、SVG、300dpi PNG、合成数据映射和英文图注。
- 原图表契约中可选的面板计划和样式引用增加结构/字节校验；旧合同兼容。自动检查不授予审美或科学通过。

预设仍为12角色、默认两名编程手、深度2和单写入者。论文负责人继续派发写作、图表与排版，不增加主管层或独立调度平台。

## 可复用入口

- 学习库：`project-template/references/award-patterns/catalog.json`；图书式索引只按任务目的读取，填好内容卡仍作为既有固定版本任务输入。
- 合成图库：`gallery/README.md`；源脚本读取单一样式配置，契约和输出哈希随实际重建更新。
- 当前源码检查：`python tools/verify-v022.py --run-tests --output audit/v0.2.2/source-verification.json`。检查器分别报告源码、声明引用和软件测试；行为、视觉、部署未检验时保持未评。

图库生成需要本机实际存在的Nature Figure和Fireworks技能及其工具。不能把已安装、已读取、已执行、已验收混成一个状态。缺依赖时如实报告。

## 验证安排与状态

1. 六组局部成对任务：结果选图、拥挤面板、公式页、结果型摘要、跨问语义、不确定性表达。
2. B专题使用明确标注的合成水资源小实例；C专题使用官方Wordle数据进行时间有序的一步预测。冻结结果供两版相同输入，不许写作角色偷调参或改数据。
3. 候选版单独完整运行2023 A，交付含图表、公式的整篇英文论文、LaTeX、PDF、复现及独立审阅。题目解答与获奖论文不进入本轮学习库。
4. H0选题、H1路线、H2关键结果、H3最终PDF分别由真实用户确认。每次批准只覆盖对应版本和证据，不从方案批准推断科学批准。

本候选已经完成学习库、合成图库与软件/隔离原生机制验证；真实模型的成对对照、完整A题和正式安装仍须另有实际证据。当前不宣称发布就绪、三题型全流程通过或任何获奖概率。

合成图库独立审阅发现过SVG marker在PDF中丢失箭头头部；已改为显式几何箭头，重新生成并按新哈希复验。修前记录保留在私有证据区，未用新哈希冒称旧版通过。

## 发布与恢复

沿用官方DSH安装方式，正常退出后再更新同一插件ID；不热覆盖活跃Host。正式切换前备份旧插件、Skill入口及相关配置，失败按本次收据恢复。真实模型测试保持现有模型配置，记录实际模型、调用与产物；不将确定性夹具冒称外部模型自主表现。

新证据在公开前脱敏，凭据、原始会话、私人源材料、安装备份和原比赛项目不上传。历史0.2.0/0.2.1报告与校验清单保持各自历史含义，不能证明本版新字节通过。
