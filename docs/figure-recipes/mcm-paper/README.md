# 基于美赛资源包的图文简报示例

这些示例是任务简报，不是新计算、新图稿或已获科学批准的结果。按已有figure-contract/context pack填入实际版本和哈希；没有所需结果时请求上游补齐，不能用范文数字代填。

## A类：机制图、方程与对照相接

参考2024 A 2405424 PDF p.13 Figure 7及p.17 Figure 12。先给当前模型的状态量、反馈方向及方程项，画必要变量/关系及正负作用；同一情景或子系统可用浅色分组。再从固定输入包比较基线与新增机制，图上保留全部有效响应和扰动时刻，必要时用对齐分面区分量纲。

交付要能回答：新增关系对应哪一项公式、改变什么输出、效果与代价分别是什么、哪组反例限制该解释。图放在对应公式与结果段附近。框图不证明因果或稳定性，颜色不替代变量定义。原图的重底、小字和双轴读数风险不作为样式目标。

## B类：全文任务链与局部更新

参考2024 B 2407038 PDF p.4 Figure 1及p.19 Figure 9。用与真实题问对应的任务带组织背景/输入、状态或轨迹、方案、执行/更新与结果；跨问箭头注明实际变量、单位、时间窗和分布/点值。允许分组容器、少量领域轮廓或坐标提示；细节多时采用主总览加局部展开，不将所有公式微缩进一张图。

算法需要解释时，用同一坐标的“一步之前→本步动作→更新之后”及紧邻公式说明。概率色阶、已处理/当前/下一状态必须有定义；是否排除某区域由模型与验证决定，不从参考图推断。将最终输出接到有条件的成本/效果与行动建议，而不只停在方法名称。

## C类：验证、区间和结论敏感性

参考2024 C 2401298 PDF p.16构件递进，以及2025 C 2510006 PDF p.14/16/23的互补图表。先固定数据截止、基线、训练/测试/未来范围，再规划“主要预测/参照→误差或失败窗口→区间/参数变化→推荐是否改变”。复杂模型可先解释可复用构件再突出新增连接，不能让网络图替代测试证据。

跨对象保持对象顺序、比较尺度和区间语义。灵敏性同时交代扰动范围、变化量及排名/策略变化，保留恒定和敏感对象；置信水平变化不等于参数敏感性。正文解释比较、数字、意义与边界，图注给样本、单位、口径与来源。需要可复核的精确数值时配表，而不是为“高级”再加一张同义图。

## 最终选择

美赛资料提供主线、验证和页面安排，通用科研图提供局部拓扑/编码；两者结合，不能互相替代。相同结果可做两个合适布局的粗图比较，但无需常态生成多套风格。选择使当前主张更容易判断的一版，再按实际尺寸核数、看图与逐页复验。
