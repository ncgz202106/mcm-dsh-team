# 优秀论文经验、三维图与终稿纠错

本轮把格式、图表和页面组织提高为大纲阶段的工作，而不是末尾美化。优先顺序是证据与规则、回答题问的完整主线、视觉论证与版面、语言精简。用户指定的论文功能顺序及人工关口不变。

## 学了什么

从用户资料中选择性查看4篇论文的23个物理PDF页，提炼12个可定位案例。记录在[呈现经验](../project-template/resources/mcm-skills/presentation-lessons.md)：机制图接方程、基线缺口接增量模型、跨问传递对象接后问、失败窗口接适用边界。每次按任务只读1–2例，不把全文塞进上下文。

样本中的微型字体、过密图和浅色线条没有作为标准复制。获奖身份沿用资料包标注，本轮没有重新验证全部奖项、公式、代码或引用。原论文、裁图和整理原稿保留在本机，仓库只存自编方法和出处位置。

## 图表与模板

- 沿用六类二维配方，新增[三维配方](figure-recipes/advanced/README.md)。两独立连续参数对应响应面，真实空间位置对应轨迹，三个实际变量也可评估三维散点。适合时主动提出立体候选，配等高线、切片或二维投影；类别柱不加装饰厚度。
- 核心图内字按最终尺寸保持12pt；同一项目共用样式。两个新合成示例全宽165.1mm、300dpi，均保留CSV、源码、PDF、SVG、PNG、英文图注与映射哈希。它们展示布局，不构成真实科学结果。
- 新项目的`paper/styles/mcm-layout.tex`集中页幅、段距、图文间距和浮动参数。正文与数学字体仍由现有骨架管理；长公式按逻辑断行，不能靠整体缩小塞入。
- 每个必要结论小节对应真实图或表；共享图须在各相关节明确引用和解释。总览图描述任务接口，不能替代所有结果证据。

## 终稿检查与修复

在新项目根运行（依赖已选TeX、Poppler、pypdf与Pillow；不自动安装或联网）：

```powershell
python scripts/paper.py --root . finish --output '../finish-candidate-01'
```

输出目录必须不存在；可放项目外或项目内的`build/`下。可用`--engine xelatex --tex-command '<现有xelatex路径>'`明确编译器，`--demo`选择演练稿；其余选项见`finish --help`。

流程保存原始指纹，在独立副本中检查、编译、渲染并最多生成三轮候选。`finish.json`和每轮报告列出实际编译输入、PDF与页面哈希、修改及未关闭队列。原稿、数据、科学数字、公式、登记和批准记录不由此命令替换。停止条件包括暂停、超时、截止时间和无法安全修复。

脚本只自动收窄可测量的简单超宽PDF插图，并要求收窄后字体证据充分。字面代码、未知宏、复杂变换和混合栅格图采用保守检查；不能提取文字不代表字体合格。页面图片要真实解码，尺寸及数量必须与PDF一致。正常宽度图也检查最终字号。

正文/图内小字、必要数学上下标、图注缺失、未定义引用、溢出及稀疏页面等按上下文交排版、图表或建模负责人处理。必要上下标不是正文，禁止自动放大整式或改数学含义。大片留白、图例遮挡、面板互补和页面节奏必须实际看图判断。论文负责人整合修复，再运行新候选检查，由非作者看最终完整图和逐页PDF复验。

`mechanical_passed`、编译通过、视觉审阅和科学验收分别记录。脚本不会自动接收正式成果或批准H2/H3；未知和未关闭项保留待修，不以一项通过覆盖其他缺口。

## 本地使用与边界

重建共享配置与Codex适配后，新项目可获得新增脚本、版式和参考。已有项目先预览差异，由文件负责人整合，不覆盖原主稿和批准。全局Skill及专项分支通过带备份的安装器更新；不启动DSH、不替换活跃Host。

独立检查及实际演练证据放在`audit/presentation-2026-11-13/`。原生角色与Hook的历史未验证范围保持，不把此处图文改进当作运行时权限认证。

[四页合成试样](figure-recipes/advanced/specimen/presentation.pdf)包含最终实际入稿效果。[独立复验](../audit/presentation-2026-11-13/layout-runtime-final-review.json)确认两轮之间仅改一处插图宽度；原项目和三图不变，早期裁切及内部空白问题另经修复。它验证图文工具和流程，不是完整竞赛论文的科学验收。
