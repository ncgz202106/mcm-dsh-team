# 本项目科研图的活动审美基线

以用户美赛资源包的完整论文为主要参照，结合通用科研图学习局部语法。新任务先看题问、论证与整页效果，再选择表现形式。紧凑论文风是起点，不自动沿用通用演示文稿或UI图标皮肤，也不把所有美赛图统一成无框细线。

| 退出默认的做法 | 当前默认 |
|---|---|
| 仅装饰的大圆角卡片、无语义逐框彩底、粗重轮廓 | 无框分类/轻量分组；必要模块可用细线方框，有信息的阶段/角色可用浅色分组 |
| 无信息阴影、发光、装饰渐变和荧光红绿 | 白底、少量语义色、稳定明度与灰度可辨性；真实数值色阶保留 |
| 巨幅图内标题、重复长警示、虚增画布 | 图内只保留必要面板/短标签；解释放图注，按内容安排画布 |
| 密集神经连线、乱穿箭头、重复图例 | 少量可解释组件、固定端口、独立反馈通道和共享图例 |
| 用三维厚度、饼图切片或高饱和颜色制造高级感 | 按数据和比较任务选图；三维用于真实空间/三变量并有二维读数 |

最初的三幅机制示意已被退回，未发布为活动示例；其大卡片版仅留在本机。重绘时数据关系和0.50/0.30/0.20权重保持，图高从165.1/165.1/177.8mm压缩至73.66/81.28/96.52mm，核心文字仍12pt。压缩来自移除卡片与巨幅标题、重排布局，而非缩字。

这不是每幅科研图都必须无框或单色的硬规定。复杂对象可以有有意义的容器、色阶或空间视图；最终由主张、读数与版面判断。历史验收PDF和图表保留原版本证据含义，不追改其哈希；不合格旧稿退出当前任务的默认引用。

## 从美赛资源包保留的正向设计

| 应当保留或重绘的表现力 | 已实际查看的参照与使用条件 |
|---|---|
| 任务带、轻量分组与共享输入/输出 | 2024 B 2407038，PDF p.4 Figure 1；分组对应题问与章节，精简微型文字而非删除真实接口 |
| 反馈符号、领域示意与关系区域 | 2024 A 2405424，PDF p.13 Figure 7；符号对应真实模型定义，重绘低对比底与小字，不因存在彩区就全部禁用 |
| 构件、层级和突出新增连接 | 2024 C 2401298，PDF p.16 Figures 9–10；先解释构件再叠加时间层，保留真实复杂性并核信息截止 |
| 概率网格、数值色阶和一步更新图 | 2024 B，PDF p.19 Figure 9；颜色编码实际状态/概率，结合更新公式，模型假设另验 |
| 共同条件对照、区间、敏感对象和配表 | 2024 A p.17 Figure 12；2025 C 2510006 PDF p.14/16/23；局部稳定与整体敏感分开，区间名称和分母重核 |

不是全篇只能两个颜色，也不是框、底色、图标、区域和整页图一律不美观。它们帮助分组、比较或解释真实对象时可采用；没有信息作用、遮挡内容或挤压可读性时才删。原论文中的字号、页数和科学结论不能替代当年规则或当前结果。
