# 本项目科研图的活动审美基线

以用户美赛资源包的完整论文及用户当前偏好为主要参照，结合通用科研图学习局部语法。新任务先看题问、论证和整页效果，再选择表现形式；不把极简、无框、细线或低饱和作为唯一审美。

| 可选表现手法 | 如何按实际效果判断 |
|---|---|
| 大圆角卡片、较重边框、每框彩底 | 均可采用；可表达分组，也可统一造型与视觉风格，检查文字空间、层级和整体搭配 |
| 装饰阴影、发光与纯装饰渐变 | 允许仅为审美与质感使用，不要求额外信息编码；检查边缘、文字/数据遮挡、打印及页面效果 |
| 荧光、高饱和或较多颜色 | 可用于鲜明风格、对照和强调；核对比、色觉/灰度可辨性，数据颜色保持清楚图例 |
| 无框线稿、浅底分组或极简布局 | 同样是可选项，适合时采用，不因更简就默认更高级 |
| 较大标题、留白、多层网络和空间造型 | 按画面节奏、结构与读数选择，指出具体问题后调整；不按类别直接扣分或否决 |

前次三幅机制教学图选择了紧凑版本，数据关系和0.50/0.30/0.20权重保持，核心文字仍12pt。这是一次具体布局取舍，旧尝试保留本机；不能因此认定圆角、彩底、较重边框或更丰富效果不适用于其他图。现有教学图仅展示部分布局，不是完整美赛审美库。

可以按需要选清爽线稿、圆角色块、层次光影、鲜明强调或空间表现，并在一篇论文中协调组合。审美装饰本身可以有价值；数据、模型关系和比例仍须准确，不能把装饰误作测量信息。历史验收PDF和图表保留原版本证据含义，不追改其哈希。

## 从美赛资源包保留的正向设计

一篇论文可以搭配不同视觉强度。验证、残差和重复对照图通常降低饱和度，给刻度、参照和数据线留出注意力。机制图、全文总览和关键发现可按需要采用更鲜明的颜色与光影。同一变量或状态的颜色含义在可比图中保持一致。立体图按需用单色柔光或数据色标，配合二维图精读。参见[三维图的科学审美](../skill-overlays/nature-figure/references/mcm-visual-recipes.md#三维图的科学审美)。

| 应当保留或重绘的表现力 | 已实际查看的参照与使用条件 |
|---|---|
| 任务带、轻量分组与共享输入/输出 | 2024 B 2407038，PDF p.4 Figure 1；分组对应题问与章节，精简微型文字而非删除真实接口 |
| 反馈符号、领域示意与关系区域 | 2024 A 2405424，PDF p.13 Figure 7；符号对应真实模型定义，重绘低对比底与小字，不因存在彩区就全部禁用 |
| 构件、层级和突出新增连接 | 2024 C 2401298，PDF p.16 Figures 9–10；先解释构件再叠加时间层，保留真实复杂性并核信息截止 |
| 概率网格、数值色阶和一步更新图 | 2024 B，PDF p.19 Figure 9；颜色编码实际状态/概率，结合更新公式，模型假设另验 |
| 共同条件对照、区间、敏感对象和配表 | 2024 A p.17 Figure 12；2025 C 2510006 PDF p.14/16/23；局部稳定与整体敏感分开，区间名称和分母重核 |

不是全篇只能两个颜色，也不是框、底色、图标、区域和整页图一律不美观。它们可以帮助解释，也可以单纯提升画面质感；不以“没有额外信息作用”为删除理由。需要调整的是具体的遮挡、对比不足、失真、搭配混乱或打印问题。原论文中的字号、页数和科学结论不能替代当年规则或当前结果。
