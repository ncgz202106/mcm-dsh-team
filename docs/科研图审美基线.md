# 本项目科研图的活动审美基线

从这批参考图学习视觉语法，同时剔除其缺点。新任务默认采用紧凑论文风，不自动沿用通用演示文稿或UI图标皮肤。

| 退出默认的做法 | 当前默认 |
|---|---|
| 大圆角卡片、每框大面积彩底、粗重轮廓 | 无框分类/轻量分组；流程仅对必要模块用细线方框 |
| 无信息阴影、发光、装饰渐变和荧光红绿 | 白底、少量语义色、稳定明度与灰度可辨性；真实数值色阶保留 |
| 巨幅图内标题、重复长警示、虚增画布 | 图内只保留必要面板/短标签；解释放图注，按内容安排画布 |
| 密集神经连线、乱穿箭头、重复图例 | 少量可解释组件、固定端口、独立反馈通道和共享图例 |
| 用三维厚度、饼图切片或高饱和颜色制造高级感 | 按数据和比较任务选图；三维用于真实空间/三变量并有二维读数 |

最初的三幅机制示意已被退回，未发布为活动示例；其大卡片版仅留在本机。重绘时数据关系和0.50/0.30/0.20权重保持，图高从165.1/165.1/177.8mm压缩至73.66/81.28/96.52mm，核心文字仍12pt。压缩来自移除卡片与巨幅标题、重排布局，而非缩字。

这不是每幅科研图都必须无框或单色的硬规定。复杂对象可以有有意义的容器、色阶或空间视图；最终由主张、读数与版面判断。历史验收PDF和图表保留原版本证据含义，不追改其哈希；不合格旧稿退出当前任务的默认引用。
