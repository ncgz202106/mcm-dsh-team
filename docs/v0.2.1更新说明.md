# v0.2.1 专项Skill与论证、图表升级

本次保持12角色、两名默认编程实例、深度2和原生派发门禁。用户论文顺序、人工关口、原演练暂停与单写入者约定继续有效。

## 五个专项Skill的条件分支

`nature-figure`、`nature-writing`、`nature-polishing`、`nature-reviewer`、`nature-statistics` 各增加一个短MCM入口与按需参考。它们仅对明确的MCM A/B/C任务生效；原Nature/通用工作流不被整目录替换。审阅分支使用父级分派的一次独立审阅，不让叶子角色启动默认三盲评。

参考源位于`skill-overlays/`，不打包上游Skill的完整副本。安装器只修改SKILL.md中的可识别条件块和一个参考文件，先备份、逐文件核验；后来修改会阻止覆盖。失败回滚和恢复失败恢复均有独立故障注入测试。它不是OS级文件锁，收据为partial时须先看本机恢复记录。

```powershell
python tools/skill-overlays.py --skills-root '<实际Skill根>'
python tools/skill-overlays.py --skills-root '<实际Skill根>' --backup-root '<仓库外本机备份目录>' --apply
python tools/skill-overlays.py --restore '<本次receipt.json>'
python tools/skill-overlays.py --restore '<本次receipt.json>' --apply
```

默认只读预检，只有`--apply`才写入。DSH和Codex各自的既有Skill版本可能不同，逐根应用，不相互覆盖完整目录。DSH的Skill监视关闭，原会话不会被宣称自动加载新内容；在安全更新后使用新会话验证。

## 预设与内容卡

- 论证设计单：答案、基线缺口、必要改变、验证、价值、代价和边界。
- 跨问传递卡：变量/单位、时间窗、点值或分布、不确定性与消费条件。
- 摘要论断记录：实际结果、基准、比较分母、条件、意义和边界，不凑数字或关键词。
- 多面板证据计划：每个面板有互补职责，先核粗图信息价值再精修。
- 页面类型与叙事压缩审阅：模型、结果、敏感性和决策页面；重复章节/表格、区间混称和失败情景纳入审查。

新字段保持可选。填好的内容卡经既有制品登记并作为任务inputs引用，沿用context-pack、版本、哈希和失效检查，不增加未核验输入旁路。

## 图表样式单一来源

默认源为 `bundle/src/figure-style.json`。修改后执行：

```powershell
node bundle/src/build.mjs --sync-project-style
node bundle/src/build.mjs --check --sync-project-style
```

构建器生成角色的默认样式说明并同步新项目默认配置；实际绘图仍读取各项目自己的 `config/figure-style.json`。移除了角色提示词中另一组近似色号。既有最终字号/插入比例检查继续使用。
