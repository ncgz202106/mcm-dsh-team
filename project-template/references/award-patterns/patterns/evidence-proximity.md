# 以页面信息组连接公式、证据和解释

这是按需方法建议，不是获奖因果规律；不覆盖题目、当年规则、用户结构、科学证据和人工关口。

## 适用

模型、结果、敏感性或决策页需要组织读者的阅读路线。

## 不适用

不是每页都需同一模板；不能为同页布局压小公式、移走关键证据或越过页数规则。

## 使用方法

模型页把目的、关键公式、符号和必要示意靠近；结果页把引导句、主图和发现解释靠近。使用自动引用、合理断行与统一层级。保留用户章节顺序，独立检查重复表格/章节、浮动图漂移、公式溢出和整页信息密度。

自编执行补充：定义与单位、句子的前后半段不因浮动图而难以串读；需要同时比较的证据尽量同时可见，确需跨页时给出接续线索。图内标签、图注与正文分工沿图表契约交接，不三遍复述。

## 验收

最终PDF逐页查看；编译通过、内容完整与视觉通过分开记录，不能让纯机械页数/字号检查自动签署视觉通过。
