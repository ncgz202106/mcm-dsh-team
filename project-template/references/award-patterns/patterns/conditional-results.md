# 摘要写成有证据和边界的答案

这是按需方法建议，不是获奖因果规律；不覆盖题目、当年规则、用户结构、科学证据和人工关口。

## 适用

论文需要在摘要或结论中压缩方法、实际发现和建议。

## 不适用

未核验结果不因摘要需要而补数字；理论结论可以用条件、界或结构结论表达。

## 使用方法

沿用户结构把摘要组织为问题目标、必要方法、主要答案、可信度与条件。复用summary-claims卡绑定数值、单位、基准和结果版本；作者原文摘要的口径冲突同样需审查。不以模型名、关键词或数字数量计分。

## 验收

摘要和正文主结果成套一致；读者能说出获得了什么而不只是使用了什么算法。
