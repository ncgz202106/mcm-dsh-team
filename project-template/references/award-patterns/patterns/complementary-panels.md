# 面板承担互补的证据任务

这是按需方法建议，不是获奖因果规律；不覆盖题目、当年规则、用户结构、科学证据和人工关口。

## 适用

两个视角共同支撑一个图级问题，例如过程响应加差值量化、估计加残差、ACF加PACF。

## 不适用

多个面板只换透视角或重复同一结论时，优先合并或删减。

## 使用方法

粗图先写图级问题与各面板职责。需要直接比较时统一量纲、范围和情景映射，必要差异显式标出。三维坐标可用于几何示意，但定量比较不得因透视遮挡丢失可读性。数据或指标变化交回建模/编程。

## 验收

删去任一面板会损失一个必要证据步骤；核数、表达和最终入稿可读性分别由对应非作者检查。
