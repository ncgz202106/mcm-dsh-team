# 优化主张先核可行性与最优性证据

这是按需方法建议，不是获奖因果规律；不覆盖题目、当年规则、用户结构、科学证据和人工关口。

## 适用

需要给出优化方案、折中候选或全局/多目标最优主张。

## 不适用

不是每题都需要Pareto前沿；只有一个政策候选时也不要以此虚构前沿。

## 使用方法

定义目标、单位、权重与约束，核查求解状态、约束残差，并给可行基准或小实例对照。单个加权解与局部数值求解不能单独证明全局Pareto结论。该样本仅作审查入口，不把作者的数值或最优性称谓当作已验证事实。

## 验收

主张强度与证据一致；目标口径能在摘要、图表和结果包中对账，未证全局时如实标注限制。
