# MCM A/B/C 论文经验库

这里保存自编的案例观察和按需模式，不保存论文、截图、用户整理原稿或本机路径。当前9个案例按A/B/C各3篇覆盖2024和2025；原先四篇MCM案例继续使用，补充同题异路线与跨年A/B。ICM E只保留在私有研究背景中，未纳入本库。

## 怎么使用

从catalog按当前论证目的、任务专长和角色选1–2项；只读取所选模式及必要案例。选用的文件通过既有任务inputs及成果登记固定路径、版本、哈希，不能把整个库预载进每个上下文。填好的论证、跨问传递、图表与摘要卡仍走既有模板和核验，不再创建平行工作流。

file相对于catalog所在目录；source_case_ids解析到cases/<id>.json。六类category分别是model-progression、cross-question、result-evidence、decision、figure、summary-layout。catalog角色使用实际preset ID。

## 证据边界

每个案例记录被学习PDF的SHA256、公开来源、官方结果表逐队核验与物理页码。官方名单证明获奖身份，不认证公开PDF就是正式提交字节，也不证明模型科学正确。公共镜像的字节核对状态另列；没有核对的不能冒称已认证。

本轮阅读正文上下文并实际渲染、查看代表模型/公式/图表/版面页，明确区分抽取文字、视觉观察、算术点检与完整复现。两篇2025 A/B公开副本为图像型PDF：实际视觉阅读，但不声称已提取可搜索正文或测得PDF文字字号。没有对9篇做完整数值复现，也没有对每一页签署视觉通过。

所有模式状态为observed_pattern_not_causal_award_rule：可以供新任务试用，不能自动打分、保证O奖或覆盖当前项目的规则与批准。保留获奖样本的风险和反例，只有新案例验证后的可迁移经验才适合升级成角色执行要求。保留题答案与解读未纳入本库。

## 原创与公开

只发布自编中文归纳及可追溯的公开链接、页码、哈希；不提供第三方论文的再分发许可。使用时仍应按实际引用内容标注来源，不复制作者措辞、图像和数值来装饰新论文。
